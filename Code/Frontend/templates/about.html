About Telugu Handwritten OCR

A deep-learning OCR system for handwritten Telugu characters. It compares a compact MobileNetV3-Small baseline with a proposed stroke-gated fusion network, then turns predictions into Telugu Unicode text and corrects words with a dictionary.

⚙End-to-end pipeline

1DatasetTelugu handwritten characters, 4 groups
2PreprocessingPolarity fix, crop to the ink, square canvas, resize, non-local-means denoising, CLAHE
3Two modelsBaseline vs. SGF-MobileNetV3, then best one selected
4UnicodeClass index → Telugu Unicode string
5CorrectionAkshara-level dictionary edit distance
6Final textOutput with per-character confidence

The two models

1Baseline · MobileNetV3-Small

A reduced-capacity MobileNetV3-Small that keeps only the early feature stages (about 0.20 M parameters) followed by pooling and a classifier. It keeps the same model family while leaving room to measure what stroke features add.

2Proposed · SGF-MobileNetV3 Selected

Full MobileNetV3-Small for appearance (576-d) plus a lightweight stroke CNN (128-d) fed with skeleton, stroke-width and edge maps. A learned gate mixes both streams:

g = σ(W·[f_app ‖ f_stroke])
f = g ⊙ f_app + (1 − g) ⊙ f_stroke

📁Dataset groups

292,752 handwritten images in 121 dataset folders. Folders that are the same Telugu character are merged, giving 76 classes, and the data is balanced to 73,463 images.

  • Achulu — vowels (అ ఆ ఇ ఈ ...)
  • Hallulu — consonants (క ఖ గ ఘ ...)
  • Guninthamulu — consonant + vowel sign (కా కి కీ ...)
  • Othulu — conjunct subscripts (్క ్ఖ ...)

🔧Technology

PyTorchTorchVisionOpenCVscikit-imageFlaskMySQLReportLabPillow

Training used AdamW with a OneCycle learning-rate schedule, label smoothing, mixed precision, early stopping, class-balanced sampling and upload-style augmentation (shift, shear, scale, blur, low resolution). The exact preprocessing code is shared between training and this web app.

⚠Good to know

  • The app recognises one cropped character per image. A word is read by uploading its character images in order.
  • Confidence scores below the threshold are flagged, with the top alternatives shown.
  • Dictionary correction helps most with single-character errors; unknown words are left as predicted.
  • Predictions are machine output — verify important text manually.
