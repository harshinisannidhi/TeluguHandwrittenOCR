Why it works better

✎Stroke features

A light CNN studies the skeleton, stroke width and edge magnitude of each character — the details that separate look-alike Telugu letters.

⚙Gated fusion

A learned gate decides, per feature, how much to trust the MobileNetV3 appearance features versus the stroke features.

📖Dictionary correction

Predicted aksharas are compared with a Telugu word list using edit distance, repairing single-character slips.
